# SAIA Studio

AI-augmented music production workstation. Built for African Horrorcore, Amapiano-Trap, and direct-to-fan sovereignty.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- No external state library

## Modules

- **Prompt Generator** — Build AI music generation prompts with sliders + tag selectors
- **Reference Lab** — Curate sonic references
- **Sample Pack Builder** — Define and export sample kits
- **Pitch Room** — Sync licensing and placement decks
- **Export Panel** — Export session data + API integration

## Dev

```bash
npm install
npm run dev
```

## Env

```
VITE_SUNO_API_KEY=your_key_here
```

## Deploy

Vercel. Set `VITE_SUNO_API_KEY` in environment variables.
